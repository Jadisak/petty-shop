# 🐾 PETTY SHOP — ผู้ช่วยการขายของเจ๊บนแท็บเล็ต

> “รักษาการขายแบบสนทนา ลดงานจดซ้ำ และไม่สร้างภาระหลังร้านเพิ่ม”  
> เจ๊เป็นคนขายและแนะนำสินค้า พนักงานเป็นคนจัดของ แท็บเล็ตช่วยจำรายการ รวมยอด แสดง QR และรวบรวมข้อมูลส่งบัญชีตอนสิ้นวัน

---

## 🌟 จุดเด่นและแนวทางการออกแบบ (Philosophy)

1. **ไม่เปลี่ยนเจ๊เป็นแคชเชียร์สะดวกซื้อ**: ไม่บังคับสแกนบาร์โค้ดทุกชิ้น ไม่บังคับถามเบอร์โทร ไม่บังคับสมัครสมาชิก
2. **ทำตามจังหวะบทสนทนา**: เจ๊รับออเดอร์ไปพร้อมกับสั่งพนักงานหยิบของได้ สามารถเปลี่ยน เพิ่ม หรือแนะนำสินค้าได้ตลอดเวลา
3. **ระบบจัดของหน้าร้าน**: เช็ก `[✓] จัดของแล้ว` เพื่อยืนยันว่าของมาวางบนเคาน์เตอร์จริง ไม่ได้มีไว้ตัดสต็อกคลัง
4. **เปิดเทียบสินค้า 2 รายการ (Compare)**: มีข้อมูลพูดคุยเตรียมไว้ให้เจ๊ เช่น วัยที่เหมาะ จุดเด่นสั้น ๆ ราคาต่อหน่วย
5. **ชำระเงินรวดเร็วและปลอดภัย**: รวมยอดใหญ่ชัดเจน แสดง QR PromptPay มาตรฐาน EMVCo พร้อมเตือนให้เจ๊ตรวจเงินเข้าก่อนกดยืนยัน หรือรับเงินสดพร้อมคำนวณเงินทอน
6. **Local-First & IndexedDB**: ข้อมูลทั้งหมดอยู่ในเครื่อง ทำงานออฟไลน์ได้ 100% ไม่ต้องต่อเน็ตระหว่างวัน
7. **สิ้นวันปุ่มเดียวสร้างชุดส่งบัญชี**:
   - 📑 สรุปรายวัน (Daily Report PDF / พิมพ์)
   - 📊 รายการขาย (Bills CSV)
   - 📋 รายละเอียดสินค้าแยกชิ้น (Items CSV)
   - 💾 ไฟล์สำรองข้อมูลระบบ (Backup JSON)

## 🚀 วิธีเปิดใช้งาน

### 1. เปิดผ่าน Local Server (แนะนำสำหรับการทดสอบและการใช้งานบนแท็บเล็ต)

รันคำสั่งใน Terminal:
```bash
# วิธีที่ 1: ผ่าน Python
npm run dev
# หรือ
python3 -m http.server 3000

# วิธีที่ 2: ผ่าน Node.js serve
npm start
```

จากนั้นเปิดเบราว์เซอร์ไปที่:
👉 **`http://localhost:3000`**

*(หากใช้งานบนแท็บเล็ต iPad / Android ให้เปิด IP ของเครื่องคอมพิวเตอร์ในวง Wi-Fi เดียวกัน เช่น `http://192.168.1.xxx:3000` แล้วกด "Add to Home Screen" เพื่อใช้งานเสมือนแอปเต็มจอ)*

### 2. เปิดไฟล์โดยตรง
สามารถดับเบิลคลิกเปิดไฟล์ `index.html` บนเบราว์เซอร์ Google Chrome, Safari หรือ Edge ได้ทันที

## 📱 หน้าจอหลัก 3 ส่วน + ฟังก์ชันพิเศษ

1. **🛒 ช่วยขาย (POS Assistant)**:
   - ค้นหาด้วยชื่อเรียกจริง เช่น *“ไก่ทูน่า”*, *“คานิว่า”*, *“ไม่เค็ม”*, *“แมวเด็ก”*
   - แถบฟิลเตอร์: ขายบ่อย 🔥, เจ๊แนะนำ ⭐, อาหารแมว 🐱, อาหารสุนัข 🐶, อาหารเปียก/ขนม 🥫, ทรายและของใช้ 📦
   - บอร์ดออเดอร์: ใส่ชื่อเล่นบิล (เช่น *“พี่เสื้อฟ้า”*), เช็ก `[✓] จัดของแล้ว`, ปรับลดราคาเฉพาะชิ้น, พักบิลสลับรับลูกค้าคนอื่น
2. **📋 รายการวันนี้ (Today's Journal)**:
   - ดูประวัติบิลวันนี้ ยอดเงินสด ยอด QR
   - แนบรูปสลิปเงินโอนหรือภาพถ่ายของจริงลงในบิล (เก็บใน IndexedDB)
   - ยกเลิกบิลหรือพิมพ์ใบเสร็จย้อนหลัง
3. **📦 ปิดวัน / ส่งบัญชี (End of Day)**:
   - ตรวจนับเงินสดในเก๊ะเทียบกับระบบ
   - ดาวน์โหลดรายงานและไฟล์ CSV ส่งต่อสำนักงานบัญชีได้ทันที
   - ปุ่มบันทึกสถานะ "ส่งสำนักงานบัญชีแล้ว" พร้อมเวลา
4. **⚙️ สมุดสินค้า & ตั้งค่า**:
   - นำเข้า / ส่งออก CSV (ใช้ร่วมกับ Google Sheets ได้)
   - แก้ราคาหน้างาน ปักหมุดขายบ่อย/เจ๊แนะนำ หรือซ่อนสินค้า
   - ตั้งค่าเบอร์พร้อมเพย์และชื่อร้าน
